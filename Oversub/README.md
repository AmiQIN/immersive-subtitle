# Oversub 沉浸字幕

把电脑里播放的中文实时变成屏幕上的英文字幕。看视频、打游戏时挂在最上层，边看边泡在英语里。

## 功能

- **实时双语字幕**：回采系统播放声音（loopback，不占麦克风），本机识别 + 翻译，悬浮条置顶显示英文，可开中英对照模式
- **本机离线运行**：faster-whisper 识别 + Argos Translate 中→英离线翻译；也可填 Key 切到在线模型，语音和记录默认不外传
- **悬浮字幕条**：当前句 + 上一句，说话人分色；穿透模式不挡操作，交互模式可划词、收藏、定位；字号、位置、背板透明度可调
- **划词查义**：双击英文拆词，场景词库优先给游戏 / 影视 / 口语释义，查不到不编造
- **生词本与收藏**：整句、单词都能收；同一词聚合为词卡，挂全部语境；收藏可带原始音频切片、时间戳与上下文
- **句对复习**：听力句对（英→中）与输出句对（中→英）两条独立链路，含对话链、表达缺口、语用冲突、复用率、应答模板
- **跟读朗读**：系统 SAPI 朗读、循环跟读、逐词高亮、语速可调；表格内可逐句发音
- **辅助学习**：场景标签联动筛选、反向自测、质量标注、备选英文、同义簇、语境回放、语用提示、批量操作
- **可选声纹辨人**：按说话人分色；默认关闭，灵敏度在设置里调节
- **记录与导出**：按天存本地，会话分组；导出 Markdown / 中英对照 TXT / SRT / Anki CSV / CSV / OpenAI JSONL，支持导入 CSV / JSONL
- **全局热键**：全部可在设置里重录；六套界面风格；高 / 均衡 / 省电性能档位

## 怎么用

1. 从源码运行：在装好依赖的 Python 环境中运行 `oversub.py`，或双击 `启动沉浸字幕.cmd`。
2. 首次启动等 20～40 秒加载识别与翻译模型；之后正常播放视频或游戏即可，说话停顿后字幕出现。
3. 关掉主窗口不会退出，程序缩到系统托盘；从托盘菜单「退出」才是真正关闭。

## 界面与操作

- **主窗口**：状态卡（引擎 / 识别模型 / 音源）、当前字幕、记录页、生词本、收藏、句对；底部暂停 / 继续与悬浮字幕开关。
- **悬浮字幕条**：常态鼠标穿透，不挡游戏操作；按 `Ctrl+Alt+G` 进入交互模式，可点收藏、划词、拖选英文；`ESC`、点画面外或无操作超时退回穿透。
- **记录页**：右键一行可收藏、拆词、复制中文；双击英文查词；单击悬浮字幕可定位到对应记录行。
- **托盘菜单**：显示主窗口、显示 / 隐藏悬浮条、暂停 / 继续、退出。

## 工作原理

```
系统播放声音 ──► Whisper 识别 ──►（可选）声纹辨人 ──► 术语替换 + 翻译 ──► 悬浮条 / 主窗口
```

- **抓声音**：Windows 扬声器回放（loopback），不占用麦克风。
- **识别**：faster-whisper，自动选择模型——有显卡且本地有 `medium` 用 `medium`，否则 `turbo`；无显卡回退 `small` + CPU。
- **翻译**：Argos Translate 离线中→英；术语先替换成标准英文；可在设置里切在线模型。
- **降噪**：降噪强度、VAD 灵敏度、断句阈值可调，提供 FPS / 看视频 / 语音聊天场景预设；静音与过短片段自动过滤。
- 默认离线，不上传语音；接入在线接口时，请求从本机直连你填写的地址。

## 记录与存储

- 记录按天写入本地文件，旧日期自动压缩；生词本、收藏、句对均存本机。
- 记录保留期可选 永久 / 90 天 / 30 天 / 7 天。
- 配置、日志、历史、音频切片与缓存目录都在本机，不纳入仓库（见根目录 `.gitignore`）。

## 环境要求

- **操作系统**：Windows。
- **源码运行**：Python 环境，主要依赖 PySide6、faster-whisper、Argos Translate、NumPy、torch、speechbrain、soundcard、OpenCC；首次使用需下载识别与翻译模型。
- **显卡加速（可选）**：将 cuBLAS 运行库放在程序同级目录即可自动加载，缺失时静默回退 CPU。

## 已知限制

- 真·独占全屏会盖住置顶窗口，请改用无边框窗口或窗口化全屏。
- 逐词高亮按整句时长等分，语速很慢或长句末尾可能有轻微漂移。
- 朗读音色只有系统自带的英文 Zira、中文 Huihui；更多音色需在 Windows 设置里安装语言语音包。
- 背景音乐人声、语音通话也会被识别翻译；只想要特定声音时先关掉其他音源或暂停。
- 离线小模型对长句、俗语翻译有限，切在线引擎可改善。
- 目前只处理声音，聊天文字 OCR 尚未支持。
- 显卡环境下说话到字幕约 1 秒延迟；纯 CPU 识别明显更慢，不是逐字同传。
- 噪声大、多人抢话或片段过短时，声纹可能不标注。
