# Oversub 沉浸字幕

把电脑里播放的声音实时变成屏幕上的对照字幕。看视频、打游戏时挂在最上层，边看边泡在目标语言里；默认中文听成英文，也可切成英文听成中文。

## 功能

- **实时双语字幕**：回采系统播放声音（loopback，不占麦克风），本机识别 + 翻译，悬浮条置顶显示；支持中↔英双向——中文识别翻英文，也可英文识别翻中文，可开对照模式
- **本机离线运行**：faster-whisper 识别 + Argos Translate 离线翻译；也可填 Key 切到在线模型，语音和记录默认不外传
- **悬浮字幕条（对话框形态）**：默认只显示当前句，Galgame 对话框式固定尺寸，宽高不随字幕长短变化，仅可在交互模式下从右下角拖拽调整；句子超长时自动缩小字号而不是撑大窗口，对话框高度可在设置里用滑块微调（或回到按字号自动档）；穿透模式不挡操作，交互模式可划词、收藏、定位；位置、背板透明度可调；可一键锚定屏幕顶部 / 底部，拖出屏幕后一键复位，顶部留白可压游戏 HUD；状态 / 控制行默认收起，进入交互模式才露出
- **多套字幕皮肤**：深色卡片、Galgame 浅色（柚子社风）、ATRI 冷调、滚动歌词、电影字幕、纸质米黄、磨砂玻璃、纯黑白框、赛博霓虹、琥珀复古等成品样式，外加「自定义颜色」（底色 / 主字幕 / 副字幕点色即生效）与自定义底图；只换底色、描边、圆角、字色与对齐，不影响采集、翻译、历史等任何逻辑；首页下拉或设置页即时切换
- **热词偏置**：热词模式分 关闭 / 自定义 / 全表三档；自定义热词（人名、术语、网络词）只在本机并入 ASR 提示，不上传；内置游戏、动漫、日常词表按需选用
- **点词查义与生词卡**：单击单词弹出词卡查义并存生词，双击英文拆整句；场景词库优先给游戏 / 影视 / 口语释义，查不到不编造
- **生词本与收藏**：整句、单词都能收；同一词聚合为词卡，挂全部语境；收藏可带原始音频切片、时间戳与上下文
- **句对复习**：听力句对（英→中）与输出句对（中→英）两条独立链路，含对话链、表达缺口、语用冲突、复用率、应答模板
- **跟读朗读**：系统 SAPI 朗读、循环跟读、逐词高亮、语速可调；表格内可逐句发音
- **双向语音辅助（可选，默认关）**：麦克风说中文，旁边小卡给出英文说法，可并入句对复习
- **辅助学习**：场景标签联动筛选、反向自测、质量标注、备选英文、同义簇、语境回放、语用提示、批量操作
- **可选声纹辨人**：按说话人分色；默认关闭，灵敏度在设置里调节
- **记录与导出**：按天存本地，会话分组；导出 Markdown / 中英对照 TXT / SRT / Anki CSV / CSV / OpenAI JSONL，支持导入 CSV / JSONL
- **全局热键**：全部可在设置里重录；主窗口六套界面主题；高 / 均衡 / 省电性能档位

## 怎么用

1. **免安装包**：从 Releases 下载最新压缩包，解压后双击 `Oversub.exe`；或从源码运行——在装好依赖的 Python 环境中运行 `oversub.py`，也可双击 `启动沉浸字幕.cmd`。
2. 首次启动等 20～40 秒加载识别与翻译模型；引擎就绪后停在待命状态，点主窗口「开始捕获」才开始监听。之后正常播放视频或游戏即可，说话停顿后字幕出现。
3. 关掉主窗口不会退出，程序缩到系统托盘；从托盘菜单「退出」才是真正关闭。

## 界面与操作

- **主窗口**：状态卡（引擎 / 识别模型 / 音源）、当前字幕、记录页、生词本、收藏、句对；首页第一屏是外观快捷条——字幕皮肤、字幕位置、界面字号 A− / A+、快捷键一览；设置内嵌为主窗口的一个页面，不再弹独立小窗；底部暂停 / 继续与悬浮字幕开关。
- **悬浮字幕条**：常态鼠标穿透，不挡游戏操作；按 `Ctrl+Alt+G` 进入交互模式，可点收藏、划词、拖选英文；快捷按钮含一键收藏、顶 / 底锚定切换、更多菜单；`ESC`、点画面外或无操作超时退回穿透。位置拖出屏幕或换显示器后，可在更多菜单里一键复位到顶部。
- **记录页**：右键一行可收藏、拆词、复制中文；双击英文查词；单击悬浮字幕可定位到对应记录行。
- **托盘菜单**：显示主窗口、显示 / 隐藏悬浮条、暂停 / 继续、退出。

## 工作原理

```
系统播放声音 ──► Whisper 识别 ──►（可选）声纹辨人 ──► 术语替换 + 翻译 ──► 悬浮条 / 主窗口
```

- **抓声音**：Windows 扬声器回放（loopback），不占用麦克风。
- **识别**：faster-whisper，自动选择模型——有显卡且本地有 `medium` 用 `medium`，否则 `turbo`；无显卡回退 `small` + CPU。
- **翻译**：Argos Translate 离线翻译，方向按句配对（默认中→英，可切英→中）；术语先替换成标准英文；可在设置里切在线模型。设置页的翻译包表只读展示本机 Argos 包的真实安装状态，软件内不提供其他语种的下载 / 卸载；未接入的语种不出现在下拉里，也不提供假下载入口。
- **降噪**：降噪强度、VAD 灵敏度、断句阈值可调，提供 FPS / 看视频 / 语音聊天场景预设；静音与过短片段自动过滤。
- 默认离线，不上传语音；接入在线接口时，请求从本机直连你填写的地址。

## 记录与存储

- 记录按天写入本地文件，旧日期自动压缩；生词本、收藏、句对均存本机。
- 记录保留期可选 永久 / 90 天 / 30 天 / 7 天。
- 配置、日志、历史、音频切片与缓存目录都在本机，不纳入仓库（见根目录 `.gitignore`）。

## 环境要求

- **操作系统**：Windows。
- **免安装包**：Releases 压缩包已带齐运行库与中英离线翻译包，解压即用，无需装 Python；识别模型首次使用时下载。
- **源码运行**：Python 环境，主要依赖 PySide6、faster-whisper、Argos Translate、NumPy、torch、speechbrain、soundcard、OpenCC；首次使用需自行准备识别模型与中英翻译包。
- **显卡加速（可选）**：将 cuBLAS 运行库放在程序同级目录即可自动加载，缺失时静默回退 CPU。

## 已知限制

- 真·独占全屏会盖住置顶窗口，请改用无边框窗口或窗口化全屏。
- 逐词高亮按整句时长等分，语速很慢或长句末尾可能有轻微漂移。
- 朗读音色只有系统自带的英文 Zira、中文 Huihui；更多音色需在 Windows 设置里安装语言语音包。
- 背景音乐人声、语音通话也会被识别翻译；只想要特定声音时先关掉其他音源或暂停。
- 离线小模型对长句、俗语翻译有限，切在线引擎可改善。
- 目前只处理声音，聊天文字 OCR 尚未支持。
- 显卡环境下说话到字幕约 1 秒延迟；纯 CPU 识别明显更慢，不是逐字同传。
- 噪声大、多人抢话或片段过短时，声纹可能不标注。
