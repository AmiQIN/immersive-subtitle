# SceneTalk 情景译

Windows 桌面小工具：把你脑子里冒出来的中文，变成那个场景下英语母语者真会说的话，然后自动攒起来按遗忘曲线复习。

## 怎么打开

- **从 Oversub 进入（打包版主要入口）**：启动 Oversub 后，左侧点「说 / SceneTalk」页签即可；页面由主程序内置的本机小服务提供，不需要单独起脚本。
- **独立启动**：双击 `启动SceneTalk.cmd`，会弹出一个独立窗口（不是浏览器标签页）。

- 启动脚本会用一个只监听本机 127.0.0.1 的小服务给页面提供运行环境，这是浏览器允许使用麦克风的前提。
- 关掉窗口后，后台进程大约 45 秒自动退出，不会常驻。
- 想固定到任务栏：右键 `启动SceneTalk.cmd` → 发送到 → 桌面快捷方式，再把快捷方式拖到任务栏。

## 怎么用

1. 左边选一个情境（点餐、面试、课堂讨论…），或者点「不限」。
2. 按下绿色麦克风说中文，说完会自动生成；也可以直接打字，然后按 `Ctrl + Enter`。
3. 右边给出：英文主句、语气标签、两条替换说法、一条读法提示（连读／弱读／重音）。
4. 生成的句子自动进入语料库，当天就出现在「复习」里。

## 三个页签

- **对话**：主要入口。左侧「今天收集」是今天生成的句子，点一下回到那张卡。
- **复习**：到期的句子先只显示中文，想好再揭晓英文，然后自评「没想起来／勉强想起／张口就来」，间隔按 1、3、7、16、35、90 天推进。
- **语料库**：按情境分组，可搜索、朗读、删除，也能导出 JSON 备份。
- **设置**：换引擎、调难度和语气、选音色语速、导入导出。

## 两种生成引擎

**内置语料（默认）**：60 句、12 个情境，离线可用，按中文关键词匹配。适合没配密钥时先跑通流程。

**在线模型**：任意 OpenAI 兼容接口，按你的原话生成，覆盖范围不受语料限制。设置页填三项：

| 项 | 例子 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型名 | `deepseek-chat` |
| API Key | `sk-…` |

也支持本地 Ollama：地址填 `http://localhost:11434/v1`，模型名填你本地的模型，Key 随便填一个非空字符。

密钥只写进本机浏览器的 localStorage，不上传任何地方。生成的请求直接从你电脑发到你填的那个接口。

## 已知限制

- **语音识别**依赖 Edge 的在线识别服务，没网就不行；Windows 上偶尔会在识别服务上抽风，此时直接打字（打字一样会触发自动入库）。
- **内置语料只有 60 句**，超出范围会提示「这句还没收录」，并给出语料库里最接近的三句。想要任意一句都能翻，得配在线模型。
- **没有跟读评分**：目前只能听、跟读、自己判断，没有发音打分（那需要额外的声学对比模型）。
- 数据存在本机浏览器存储里，清浏览器数据会一起清掉，重要句子请用「导出 JSON」备份。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `SceneTalk.html` | 全部界面和逻辑，单文件自包含 |
| `server.pyw` | 起本地服务并打开 Edge 应用窗口，兼做窗口关闭后的自动退出 |
| `启动SceneTalk.cmd` | 双击入口 |
